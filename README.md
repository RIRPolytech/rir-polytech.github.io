# RIR - Polytech Lyon Robotics Association

Official repository for the website of RIR (Robotique des Ingénieurs de Roanne), the student robotics association of Polytech Lyon. 

We bring together future engineers to design autonomous robots for the French Robotics Cup. Beyond the competition, our members collaborate on innovative engineering projects, including a closed-loop PLA recycling line and custom CNC manufacturing tools.

Built using the [Solid State](https://html5up.net/solid-state) template by HTML5 UP and hosted on GitHub Pages.
